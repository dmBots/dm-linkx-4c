# EtherCAT SDK 0.3.0 版本说明

版本：**0.3.0 预览版 / C ABI 1**。适用于通过 EtherCAT 使用 LinkX4C 四路 CAN / CAN FD 的 C/C++ 应用；C# 提供 ABI 布局和加载示例。

## 兼容性

| 项目 | 支持范围 |
| --- | --- |
| Windows | x64，随包提供独立动态 SOEM 2.0.0；不支持其他 SOEM 版本 |
| Linux | x86_64，IgH 1.5.4 / API 1.5；IgH 库及内核模块另行准备 |
| 设备 | 单网卡/主站、单台 LinkX4C、通道编号 0..3 |
| 协议 | PDO v8，下行 1328B、上行 1304B；需匹配的从站固件 |
| 同步 | 默认 SM / 1ms；DC-SYNC0 需显式选择 |

Windows 还需要 Npcap 的 WinPcap API 兼容支持和 MSVC x64 Release 运行时。Linux 需要完成主站网卡配置，并具备目标 `/dev/EtherCAT<n>` 的读写权限。两平台使用相同 C API，但不能混用动态库或后端。

## 提供的功能与资料

- 四通道 CAN / CAN FD 帧提交、批量接收回调、通道位率配置及运行统计。
- 每通道有界队列和帧聚合，应用无需装配 PDO 或管理从站 credit。
- 公共 C 头、CMake 导入目标、C/C++ 收发示例及 C# ABI 示例。
- 包内 README、快速入门、ABI 参考、已知问题、第三方说明和 AI 接入 Skill。

完整接入步骤见解压目录的 `README.md`；接口布局和调用约束见 `docs/ABI_V1.md`。使用同一发行包的头文件、库和示例，不要混用旧版 SDK 或历史 Demo。

## 使用限制

本版本仍有缺帧、错载荷及 WKC 不足记录。需要端到端可靠交付时，应在应用中核对 ID、通道、DLC、完整载荷和业务序号；不要将 `submit` 成功或 `tx_submitted` 计数当作 CAN 已完成发送。

`stop` 不是发送完成屏障；`get_sync_status.active` 不是 DC_LOCKED。Windows 普通调度不保证硬实时。当前没有同步阻塞收帧、等待 CAN 完成的 flush、任意 SDO、自动断线恢复或完整 C# 封装。

更完整的现象、影响及使用建议见包内 `docs/KNOWN_ISSUES.md`。部署前请在自己的硬件、固件和负载条件下验证；本预览版不提供生产无损或长期稳定性保证。
